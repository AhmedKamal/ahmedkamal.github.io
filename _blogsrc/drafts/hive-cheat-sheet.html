While working with Spark SQL and Hive, one sometimes find himself in need for collecting some metadata info about the structure of the table getting queryed.

In this post, I'm going to collect all the hard to find hive and spark sql commands that shall make your life easier next time you are trying to extract these information.

First let's start by getting some info about our hive database

Show Tables under Database

SHOW TABLES from dbName

And if you need more details about each table, you can just use

DESCRIBE FORMATTED dbName.tableName

Cool, now we know which tables lie under this database, but what if we want to explore the partitions available under the table itself?

SHOW PARTITIONS dbName.tableName PARTITION (partitionName = 'somevalue')

Example

SHOW PARTITIONS dev_kamal.app_openings_h3 PARTITION (day = '2020-07-10')

What if we need more info about each parititon, including column data and strage information including Serde Library, InputFormat, OutputFormat and Storage Properties?

Show Partition Description

describe formatted dbName.tbl_name partition (partitionName='20131023')

Example

describe formatted dev_kamal.app_openings_h3 PARTITION (day = '2020-07-10')

You can also use

show table extended In dbName like 'tbl_name' partition (partitionName = 'somevalue')

Show table description

show table extended like 'driver_ping_parquet' partition (day='2016-11-24');
