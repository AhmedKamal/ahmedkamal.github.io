Hi, in this blog post I would like to share with you some of the experience I got dealing with the problem of data synchronization and how Microsoft Sync Framework could help you with it. In these days, it become very essential for most of the users to use more than one device. For example, you could be writing some notes in your mobile and after you go home you would like to view and edit these notes on your laptop. Synchronization may seems easy due to its existence in most application we use (OneNote, DropBox, Google Keep, .. etc)

In fact, it is quite the opposite. Synchronization is a challenging problem especially when there are multiple sources that are manipulating the same master tables. Imagine a scenario when you wrote a note on your mobile then you altered it on your pc and tablet at the same time! Who would win in this scenario and which actions would have the higher priority?!

Due to Wikipedia, Data synchronization is the process of establishing consistency among data from a source to a target data storage and vice versa and the continuous harmonization of the data over time. It is fundamental to a wide variety of applications, including file synchronization and mobile device synchronization e.g., for PDAs.[1]

One of the famous examples of the data synchronization that you may be already using is version control systems like Git (the open source distributed version control system used in Github).

Before diving deeper, you may have some questions that I would want to step them aside

  • When do I really have to do synchronization?

The simple answer is: when you want to allow users to use your app and make transactions while being not connected to the internet. This also applies to scenarios when you want to sync the data via Wi-Fi only and not to download or upload data while you are on 3G for example. Otherwise, you can depend on a real time service to handle all user’s transactions.

  • Are there any services that can help me create my own real-time API?

There are different options that provide BOOS (Back end as a service). I will try to list the few I know

  • Azure Mobile Services
  • Parse (From Facebook)
  • Helios (They describe themselves as “Extensible open source mobile backend framework” )
