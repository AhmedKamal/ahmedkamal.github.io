Hi, in this post I would like to talk about how you should handle the change of orientation in android activities.

1- Flexible UI

While designing the UI you should try to make the width, height, margins, padding and other properties of element relative to other elements instead of hard writing the values.

It is also encouraged to use dpi instead of pixel.

Density-independent pixel (dp): A virtual pixel unit that you should use when defining UI layout, to express layout dimensions or position in a density-independent way.

You can also create different layout for each orientation in addition to creating layouts for different screen sizes.

2- Saving the state

One of the things you should care about during mobile development is maintaining the state of the app each time the user take an action (Change Rotation, Closing the app, going to another page)

When the orientation of the app changes, the app loses the state of the screen so we have to save this state before going anywhere. We can create a data structure for our activity where each property represent something that we are interested in saving.

1- Searching News Articles
2- Filtering News Items by Week Days
3- Filtering News Items by Category

We may be interested in saving the the following things:

1- The query that the user may type
2- The selected filters (Date & Category)
