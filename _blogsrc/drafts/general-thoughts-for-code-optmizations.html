Make it process faster on the same resources.

  • Can we pre-compute and cache any of the bottleneck causes upfront reasonably?
  • Try Modin for Pandas
  • Optimize your algo and use Numba and to compile your code to an optimized format.
  • Pandas pitfalls https://realpython.com/fast-flexible-pandas/
  • You can also write a c wrapper and invoke it from Python and write c extensions for pandas https://pandas.pydata.org/pandas-docs/stable/user_guide/enhancingperf.html
  • If the code is in python then multithreading/multiprocessing might help if it is an option.
  • Scale out of the core. Try Ray, dask or pandas on spark on multiple machines.

In general, I would recommend looking into it in this way.

  • Profile your code
  • Can we pre-compute and cache any of the slowness causes upfront reasonably?
