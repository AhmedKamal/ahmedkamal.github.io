# ahmedkamal.me

Personal site: a single-page bio at `/`, English writing at `/blog/`, Arabic
writing at `/ar/`.

Static, served by GitHub Pages. The English blog is generated by Eleventy from
`_blogsrc/` into `blog/`, and the output is committed, so there is no build step
between a push and the live site.

To add a post, see **[PUBLISHING.md](PUBLISHING.md)**.

Thanks to @AhmedAlaa23 for helping with designing the original cover :)
